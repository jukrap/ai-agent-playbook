# Other agent hosts

Project records and artifact formats are plain Markdown/JSON. Read CURRENT.md and only the relevant linked records. Select skill directories explicitly for the host's supported installation location; the common default remains .agents/skills.

The old context hooks and package-shell wrappers were retired. Use the host's native file, execution and scheduling capabilities. Optional MCP exposes the same four project-bound read-only tools; configuring it does not grant write access.
