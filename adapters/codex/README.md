# Codex adapter

Keep common user skills in .agents/skills. Select the development profile for records, design, UI and document editing; use a separate project profile for specialized capabilities. Do not mirror skills into .codex/skills.

MCP is optional. Configure a project-bound invocation of the installed aapb mcp --project command only when wanted, and keep the common server disabled by default. Existing hooks and broad package-shell commands are retired; native execution, scheduling and file tools are preferred.

Preserve user-selected model, reasoning, context, compaction and output budgets. Inspect actual versioned capability metadata before enabling experimental context management. A local setting, a discovered skill, a rendered catalog item and an invoked tool are different observations. Plugin caches and remote account installation status are distinct; local skill path controls do not uninstall remote connectors.
