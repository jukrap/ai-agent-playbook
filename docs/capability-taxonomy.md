# Choose guidance by the missing capability

A profile is a convenient selection of skills. It does not define permission levels, a required workflow, or a desired total catalog size. Start with what the current task actually lacks.

| Need | AAPB guidance | Additional capability, if needed |
| --- | --- | --- |
| Resume work from reliable state | `project-memory` | File reading/editing and project evidence |
| Produce a specific contract or handoff | `spec-artifacts` | Relevant source/specification knowledge |
| Establish visual direction | `design-brief-direction` | Applicable design tools and product references |
| Review an existing UI | `ui-polish` | A rendered browser/device surface |
| Edit Korean/English prose | `natural-writing-humanization` | Optional document-format tools |
| Preserve old-stack behavior | `legacy-contracts` | Actual stack execution and compatibility checks |
| Simplify code safely | Selected code-cleanup references | Project-defined tests and source inspection |

A skill explains a constraint or format; a connector provides access; a runtime tool performs a defined operation. Keeping a Figma or document-generation connection can be valuable even when a generic planning instruction is redundant. Conversely, a skill file cannot substitute for an unavailable engine, browser, or account connection.

## Selection examples

For a small Korean README edit, preserve terms and meaning without automatically loading a full review framework. For a dense dashboard, inspect its workflow and rendered states before choosing visual changes. For a legacy WebView, select the relevant bridge/compatibility contract and retain the project's execution permissions.

AAPB entrypoints are selected by these roles rather than an arbitrary count. The optional light profile supplies compact continuity guidance; core and development retain the fuller formats and specialist guidance. Use [Skill catalog](skill-catalog.md) for installation, [disposition](skill-decisions.md) for old names, and [environment profiles](environment-profiles.md) for external integrations.
