# Design, UI, prose and code quality

These are different review subjects, not a single AI-likeness score.

Design direction preserves the product's purpose, reference examples, brand, density and implementation constraints. UI polish compares rendered states and accessibility around the actual task. Tool integration follows the selected design tool's own capability instructions.

Natural document editing preserves meaning, numbers, commands, URLs, terminology, register and intentional emphasis. Contextual Korean examples are not automatic replacement rules. Ordinary edits require neither CLI checks nor a rubric table. Optional writing checks remain advisory for substantive rewrites or explicit requests.

Code-structure cleanup examines unnecessary abstraction, duplication and behavior preservation. Its examples remain in the optional reference library; it is not merged with visual or prose judgments.

Fiction's accepted voice, character register and genre conventions belong to the writing product. General document rules do not authorize manuscript changes. Visual devices such as cards and gradients may be deliberate and useful.

For a bounded comparison, use the same input, task constraints, model settings and output criteria. Record fidelity, task fit, over-correction and observed execution cost separately. A small pilot does not prove a general benchmark gain.
