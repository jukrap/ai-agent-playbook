Use `aapb skills list --json` for the runtime catalog. The normal installation path is .agents/skills. Profiles select capabilities, not permission levels.

Each entrypoint is short and directs the reader to only the relevant local reference. The natural-writing skill includes contextual Korean examples as JSON data. Legacy contract references travel with the optional legacy skill.

General reasoning, review, and compatibility-wrapper skills were retired as independent entrypoints. Their substantive reference material is preserved in the optional reference library. See [the 94-row disposition](skill-decisions.md). The chosen count follows capability boundaries; a larger or smaller host catalog is measured independently.
