# Optional reference library

This library preserves domain contracts, examples and exception handling from the 0.5 generation. It is not installed as a skill catalog and is not a startup reading list. Select a relevant file only when its domain detail is needed. Historical procedural advice and retired commands are not current requirements; follow the current task and the 1.0 command guide. Source-to-destination mappings are in docs/skill-decisions.json.

Design and Korean document criteria have current short entrypoints. Code-structure cleanup remains a distinct optional reference under quality/cleanup-ai-slop. Full historical entrypoints can be recovered from the pinned 0.5.11 package.

For current root instructions and architecture selection, use [project templates](../templates/agents/README.md) and [architecture guidance](../docs/project-architecture.md). The template migration table maps the removed stack-specific root files to selected references.
