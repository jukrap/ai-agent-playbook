# Project Memory

Keep CURRENT.md as the short entrypoint for the active objective, constraints, next action, and links to supporting records. Read only records relevant to this task; ordinary edits do not require a new worklog.

Record durable decisions and verified facts at meaningful milestones. Preserve source locators and distinguish implementation, configuration, and observed runtime behavior. Existing project ownership and local-only rules apply.

Read `references/current-state.md` when updating current state or resuming work. Read `references/evidence-and-handoff.md` when recording a decision or handing work to another session. Native host memory is optional; ordinary files are sufficient.
