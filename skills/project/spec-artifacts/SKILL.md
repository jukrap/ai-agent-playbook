# Specification Artifacts

Produce only the requested artifact. Reuse the project's format and existing evidence; do not require a planning ceremony, fixed reading chain, or all artifact types.

Keep intended requirements distinct from current implementation. Identify the relevant repository or registered workspace members and the existing record destination; shared records do not authorize code or Git operations across members. Preserve local-only rules and user approval conditions.

Read `references/formats.md` for the selected artifact's fields. Preserve public API, data, version, and migration constraints when relevant. Record only verification actually performed. Detailed domain examples are optional in the repository reference library, not mandatory prerequisites.

For a long independent artifact, an optional delegated DRAFT must use bounded evidence and short relevant history. The parent reviews protected facts and unknowns before adoption; ordinary artifacts stay in the main task.
