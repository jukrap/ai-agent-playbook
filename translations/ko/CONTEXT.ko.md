# 저장소 맥락

AAPB는 일반 파일로 프로젝트 상태를 이어가고, 필요한 산출물을 만드는 지침을 제공합니다. 실행과 예약은 에이전트 앱이 맡습니다. 제품 소개는 [README](README.ko.md), 읽는 순서는 [문서 지도](docs/README.ko.md)에 있습니다.

## 용어

| 용어 | 뜻 |
| --- | --- |
| 스킬 | 작업 상황에 맞춰 선택하는 짧은 지침과 선택형 참고 자료 |
| 참고 자료 | 필요할 때 찾아보는 분야별 상세 내용이나 예시 |
| 프로젝트 기록 | 한 프로젝트의 현재 사실, 결정, 근거 |
| CURRENT.md | 현재 상태를 찾는 시작 문서. 모든 과거 행동의 대화록이 아님 |
| 관리 파일 | 도구가 소유권과 예상 해시를 기록한 파일 |
| 호스트 | 실행·편집·선택형 연동을 제공하는 에이전트 앱 |
| Forge | 검토한 협업 작업에 사용하는 GitHub/Gitea 같은 서비스 |

## 설계 의도

유용한 계약과 예시는 보존하고 중복된 필수 절차를 줄입니다. 실행은 앱과 프로젝트 도구에 맡깁니다. 변경에는 명시적 미리보기와 복구를 제공하고 설정, 로딩, 실제 실행을 구분합니다.

스킬 진입점과 새 기록 틀이 작다고 사람용 설명까지 최소화하는 것은 아닙니다. README의 브랜드, 언어별 탐색, 초보자 안내, 명령 예시, 구조 설명은 독자에게 필요한 수준을 유지해야 합니다. 배경은 [1.0 설계](docs/redesign.ko.md), 편집 기준은 [유지보수](docs/maintenance.ko.md)에 있습니다.
