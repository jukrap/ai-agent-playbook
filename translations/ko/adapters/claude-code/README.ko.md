# Claude Code와 다른 에이전트 앱

AAPB 기록은 일반 Markdown·JSON 파일이며 스킬 형식은 앱별 설정과 분리합니다. 현재 앱이 지원하는 지침·스킬 위치를 사용하세요. 모든 앱이 `.agents/skills`를 자동으로 읽는다고 가정하지 않습니다.

## 파일 사용부터 시작하기

프로젝트의 기존 지침과 CURRENT.md를 읽고 관련 링크를 따릅니다. 현재 상태, 결정, 인수인계는 일반 파일 편집으로 작성합니다. 애플리케이션 검사는 프로젝트 도구로 실행하고 실제 결과를 기록합니다.

기록이 없으면 `aapb bootstrap "<project>" --dry-run`으로 생성을 미리 봅니다. 기존 지침과 기록은 보존합니다. 전체 연습 순서는 [처음 10분 사용법](../../docs/quick-start.ko.md)에 있습니다.

## 지침 선택과 도구 연결

[스킬 카탈로그](../../docs/skill-catalog.ko.md)에서 필요한 항목을 고릅니다. 앱이 다른 설치 위치를 지원한다면 `--agents-root`로 직접 지정하고 미리보기를 확인하세요. 다른 내용은 보존하고 새 세션에서 실제 로딩을 확인합니다. CLI의 일반 기본값은 `.agents/skills`입니다.

선택형 MCP는 [MCP 설정](../../docs/mcp-permission-model.ko.md)의 프로젝트별 Node 서버를 사용합니다. 읽기 전용 기록 도구 네 개를 확인하세요. 설정을 추가한다고 파일·셸 쓰기 권한이 생기지는 않습니다.

## 종료된 훅 예시

과거 패키지 문맥 훅과 셸 래퍼는 종료했습니다. `settings.example.json`에는 비활성 상태의 빈 hooks 객체만 두고 삭제된 스크립트 명령을 뺐습니다. 설정은 필요한 부분만 합치세요. 기존 앱 설정을 이 빈 예시로 덮어쓰지 않습니다. 파일·실행·예약 기능은 앱이 맡습니다.

SDK나 다른 앱에서의 테스트가 이 앱의 현재 탐색·도구 동작을 증명하지는 않습니다. 연동 시험에서는 실제 설치 버전, 목록, 호출 결과를 기록하세요.
