# Codex 어댑터

공통 사용자 스킬은 .agents/skills에 둡니다. 기록·디자인·UI·문서 편집은 development 프로필로 선택하고 전문 기능은 별도 프로젝트 구성으로 사용합니다. .codex/skills에 중복 복제하지 않습니다.

MCP는 선택 기능입니다. 필요할 때만 설치된 aapb mcp --project 명령을 프로젝트에 연결하고 공통 서버는 기본 비활성으로 유지합니다. 기존 hook과 광범위 package-shell 명령은 종료했으며 내장 실행·예약·파일 도구를 우선합니다.

사용자가 정한 모델·추론·컨텍스트·압축·출력 예산을 보존합니다. 실험적 맥락 관리를 켜기 전 설치 버전에 맞는 실제 metadata를 확인합니다. 로컬 설정·발견된 스킬·렌더링된 항목·실제 도구 호출을 구분합니다. 캐시와 원격 계정 설치 상태는 별개이며 로컬 스킬 경로 제어가 원격 connector를 제거하지는 않습니다.
