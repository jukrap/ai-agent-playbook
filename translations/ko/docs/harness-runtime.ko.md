# 런타임 경계

이식 가능한 프로젝트 기록과 선택한 설치 동작을 제공합니다. CLI는 필요한 경우에만 스킬·MCP·글쓰기·Forge 모듈을 로딩합니다. 자율 실행기·예약기·코드 인덱스 DB·범용 preflight 서비스를 시작하지 않습니다.

기록 기능은 기존 프로젝트에 연결해 playbook 하나를 선택하고 텍스트 읽기·검색을 제한합니다. 문서 검증과 실행 증명을 구분합니다. 새 출력 envelope는 schemaVersion 2이며 기존 글쓰기·Forge schema는 유지합니다. 과거 기록과 소유권 marker를 호환해서 읽습니다.

설치는 경로·소유권·해시 확인, 준비된 새 디렉터리, 복구 journal과 보호된 rollback을 사용합니다. 이름만으로 관련 없는 내용을 관리 대상으로 간주하지 않습니다. lifecycle 가이드를 참고합니다.
