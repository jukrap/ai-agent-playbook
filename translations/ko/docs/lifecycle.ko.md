# 설치·이전·복구

기록 레이아웃은 aapb migrate layout <project> --to minimal --json으로 미리 보고 --apply를 명시해 적용합니다. 결과의 backup은 플레이북 상대 경로입니다. aapb migrate rollback <project> --backup <반환된-경로> --json으로 복구를 미리 본 다음 --apply로 변경되지 않은 메타데이터를 복원합니다. 이후의 편집은 충돌로 보존됩니다.

패키지 설치와 스킬 설치는 별개입니다. 로컬 prerelease archive는 격리된 npm prefix에서 확인합니다. install·update는 게시를 수행하지 않습니다.

## 스킬 선택

코어는 기록·규격 두 진입점, 개발은 디자인·UI·문장 세 진입점을 추가하며 레거시는 계약 진입점 하나를 설치합니다. --skill을 개별 지정하면 프로필 선택을 대체합니다. 선택한 스킬의 참조는 함께 설치하지만 큰 소스 참조 라이브러리는 자동 설치하지 않습니다.

일반 install·update는 .agents/skills의 선택 항목만 바꿉니다. .codex/skills에 복제하거나 구버전을 삭제하지 않습니다. 0.5 설치 정리는 migrate를 명시적으로 사용합니다.

## 트랜잭션

기본 백업의 상위 경로는 선택한 .agents/skills 디렉터리 옆의 aapb-backups입니다. 설치 경로를 바꿔도 기본 백업은 설치 파일시스템에 둡니다. 디렉터리를 원자적으로 이동하려면 한 트랜잭션의 백업과 실제 변경할 설치본이 같은 파일시스템에 있어야 합니다. 잘못된 --backup-root 조합은 journal 생성이나 설치 파일 변경 전에 미리보기에서 거부합니다. 여러 파일시스템에 걸친 이전은 선택 항목·설치 루트 쌍을 나누고 각각 같은 파일시스템의 백업을 사용해야 합니다. 파일시스템을 넘는 복사는 원자적 이전 모드로 지원하지 않습니다.

1. 설치와 알려진 구버전 정리를 미리 봅니다.
2. 소유권·해시·대상 경로·충돌을 확인합니다.
3. 두 설치 경로 밖의 백업 위치를 사용해 적용합니다.
4. 반환된 transaction 디렉터리와 journal을 보관합니다.
5. 호스트를 새로 로딩해 파일 변경과 실제 목록을 별도로 확인합니다.

journal은 준비·적용 중·적용 완료·복구 상태를 기록합니다. 기존 디렉터리를 백업으로 옮긴 뒤 새 설치본을 활성화합니다. 중단돼도 복구할 내용을 남기며 재실행은 현재 파일 상태를 확인합니다.

수정된 관리 파일, 미관리 파일과 링크 디렉터리는 보존합니다. 독립적인 안전 항목이 완료돼도 충돌을 보고합니다. 복구는 현재·백업 해시를 확인해 이후 사용자 편집을 덮어쓰지 않습니다. journal과 백업 내용을 수정하지 않습니다.

## 프로젝트 기록

새 bootstrap은 루트 지침을 보존하고 CURRENT.md와 metadata만 만듭니다. --local-only는 worktree를 포함한 Git-local exclude를 사용합니다. 기존 내용을 다시 bootstrap으로 덮어쓰지 않습니다.

structured 및 레거시 경로를 읽으며 여러 루트가 있으면 하나를 임의로 고르지 않습니다. 레이아웃 이전은 검토된 CURRENT.md와 변경되지 않은 관리 metadata를 요구합니다. 이전 manifest와 소유권 marker를 로컬 archive에 저장하며 사용자 기록을 다시 쓰거나 자동 요약하지 않습니다.

## 종료 명령과 정확한 복구

실행·감독 루프·예약·자동 전달은 1.0에 포함하지 않습니다. 호스트 실행·예약과 기존 프로젝트 도구로 대체합니다. 구버전 기능을 의도적으로 쓸 때는 고정 npx ai-agent-playbook@0.5.11을 사용합니다. 전역 설치 버전이 소스 기준선과 다르면 실제 이전 패키지도 따로 보존합니다.

전역 실행 파일 교체 전 기존 예약의 참조를 확인합니다. 패키지는 예약·원격 기록을 다시 쓰거나 삭제하지 않습니다. 명시적으로 선택한 복구를 위해 이전 실행 파일을 보관합니다.

PowerShell 래퍼는 같은 Node 구현을 사용합니다. update.ps1은 자동 pull을 하지 않으며 -Pull이 있을 때만 git pull --ff-only를 요청합니다. -WhatIf는 변경하지 않습니다.
