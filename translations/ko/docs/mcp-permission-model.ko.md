# 프로젝트 MCP 경계

각 도구 결과의 직렬화된 JSON은 이스케이프 문자를 포함해 12,000자로 제한됩니다. 초과한 결과는 잘린 미리보기임을 표시합니다. 검색 범위를 좁히거나 기록을 더 작은 단위로 읽으세요. 기록 본문뿐 아니라 상태와 검증 출력에도 적용됩니다.

MCP는 선택 기능이며 패키지 설치가 자동 등록하지 않습니다. aapb mcp --project <project>로 연결하며 생략하면 시작 작업 디렉터리를 사용합니다.

| 도구 | 허용하는 동작 |
| --- | --- |
| playbook_status | 기록 목록·레이아웃·진입점 |
| playbook_search | 기록 내부의 제한된 literal 검색 |
| playbook_read | playbook 상대 경로의 제한된 텍스트 읽기 |
| playbook_validate | JSON·링크·관리 파일 확인 |

도구 인자로 프로젝트 연결 대상을 바꿀 수 없습니다. 상대 경로 이탈·절대 경로·링크·junction·비텍스트 기록을 거부하거나 제외로 보고합니다. 파일 크기·출력·검색 범위를 제한하고 불완전한 탐색을 표시합니다.

쓰기 도구·동적 resource·생성 workflow prompt·shell·자동 hook·MCP를 통한 Forge 쓰기는 없습니다. 기록은 호스트 파일 도구로 편집하고 설치·이전·Forge 적용은 명시적 CLI를 사용합니다. 문서 검증이 실행 동작까지 증명하지 않습니다.

설정 활성화, 프로세스 시작, 네 도구의 노출과 실제 동작을 구분합니다. 구버전 MCP 설정은 의도적으로 이전하기 전까지 비활성 상태로 둡니다. 이전의 쓰기 활성화 플래그는 지원하지 않습니다.
