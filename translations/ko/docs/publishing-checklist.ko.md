# 릴리스 준비

패키지명과 aapb 명령을 유지합니다. prerelease 검증은 1.0.0-next.2에서 수행하고 Python metadata는 1.0.0.dev2로 대응합니다. 소스의 버전만으로 게시했다고 하지 않습니다.

안정 버전 전 구문·타입·동작·번역·공개 문서 검사, 격리 archive 설치, 이전·복구, 실제 호스트 로딩, 작은 품질 비교를 완료합니다. 미지원 플랫폼·제외 검사·미해결 사항을 기록하고 배포 목록의 로컬 자료·종료된 실행 모듈을 확인합니다.

레지스트리 게시·원격 push·릴리스 생성은 별도 권한이 필요합니다. postinstall이 스킬이나 MCP를 활성화하지 않으며 복구를 위해 소스 기준선과 실제 이전 설치를 보존합니다.
