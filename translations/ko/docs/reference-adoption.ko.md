# 참고 자료를 필요한 만큼 활용하기

선택형 자료 모음에는 이전 카탈로그의 분야별 계약, 예시, 예외 사항이 남아 있습니다. 유용한 근거로 참고하는 것과 그 자료의 모든 절차를 실행 지침으로 받아들이는 것은 다릅니다.

## 실제로 읽고 적용하는 순서

1. 부족한 내용을 정합니다. API 호환 규칙, 한국어 편집 예시, 브랜드 제약, 레거시 동작 등이 해당합니다.
2. 현재 스킬의 참고 자료나 [과거 자료의 이동 위치](skill-decisions.ko.md)를 찾습니다.
3. 범위, 날짜·버전, 전제, 실제 프로젝트와 맞는지를 확인합니다.
4. 유용한 제약이나 예시를 출처와 함께 보존하고 현재 요청에 맞게 적용합니다.
5. 다음 작업에도 필요한 프로젝트 결정이라면 프로젝트 기록에 남깁니다.

시작할 때 자료 전체를 읽거나 외부 방법론을 필수 절차로 복사하지 않습니다. 과거 명령 예시는 종료된 0.5 동작을 설명할 수 있으므로 실행 전에 [현재 명령어 가이드](commands.ko.md)를 확인하세요.

## 자료 성격 구분하기

| 자료 | 활용 기준 |
| --- | --- |
| 현재 공식 인터페이스·제품 계약 | 실제 설치 버전과 관련 원본에서 확인 |
| 구체적인 예시·알려진 예외 | 언제 적용되는지 알 수 있는 문맥 보존 |
| 벤치마크·사용 경험 | 모델, 과제, 설정, 측정 한계 구분 |
| 일반 작업 절차 | 현재 지침보다 더 제공하는 가치가 있을 때만 사용 |
| 비공개 원본·로컬 실행 결과 | 공개 패키지 문서가 아닌 승인된 로컬 위치에 보관 |

과거 참고 자료 큐·점수 CLI는 종료했습니다. 일반 파일과 조사·편집 도구로 진행하면 됩니다. 외부 자료를 적용할 때는 출처와 해당 라이선스 조건을 보존하세요. [참고 자료 모음](../references/README.ko.md)과 [1.0 변경사항과 이전 버전](redesign.ko.md)에서 배경을 볼 수 있습니다.
