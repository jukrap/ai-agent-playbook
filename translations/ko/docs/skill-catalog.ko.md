실제 목록은 aapb skills list --json으로 확인합니다. 기본 설치 위치는 .agents/skills이며 프로필은 권한이 아닌 기능을 선택합니다.

진입점은 짧게 유지하고 관련 참조만 읽도록 안내합니다. 자연스러운 글쓰기에는 한국어 예시 JSON을 포함하고 레거시 계약에는 해당 기술 참조를 함께 설치합니다.

일반 사고·검토·호환용 wrapper는 독립 진입점에서 제거하고 고유 참조는 선택 라이브러리에 남겼습니다. 94개 전수 판정표를 참고합니다. 기능 경계에 따라 구성했으며 호스트 목록 수는 별도로 측정합니다.
