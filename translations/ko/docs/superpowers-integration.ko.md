# 선택형 외부 작업 절차 도구

Superpowers는 1.0의 필수 구성이나 기본 연동이 아닙니다. AAPB가 설치하거나 켜지 않습니다. 사용자가 의도적으로 바꾸지 않는 한 기존 비활성 설정을 유지합니다.

## 다른 절차 도구를 평가할 때

실제 지침을 앱의 동작, 프로젝트 규칙, 현재 작업과 비교합니다. 고유한 계약이나 유용한 예시는 보존할 가치가 있습니다. 반면 계획, worktree 생성, 승인 질문, 정해진 리뷰 순서를 반복해서 요구하는 지침은 현재 작업에 도움 없이 부담을 더할 수 있습니다.

이 판단을 모든 외부 스킬이 해롭다는 근거로 확대하지 않습니다. 버전, 고유 기능, 필요한 도구 접근, 추가 읽기·실행, 관측한 결과, 복구 방법을 기록하세요. 사용자가 프레임워크를 선택하면 실제 충돌을 조정하고 기존 권한을 지킵니다. 모든 절차를 조용히 합쳐 강제하지 않습니다.

## 관리 범위와 복구 구분하기

AAPB 스킬을 끈다고 다른 프레임워크가 제거되거나 캐시·계정 연결이 바뀌지는 않습니다. AAPB 스킬 명령은 자신의 소유권 표식이 있는 디렉터리만 관리합니다. 다른 프로젝트와 사용자의 모델·수치 설정을 보존합니다.

전체 목록 점검은 [공통 환경 구성](environment-profiles.ko.md), 필요한 지침 선택은 [기능 선택 기준](capability-taxonomy.ko.md)을 보세요. 프로젝트의 기존 도구만으로도 일반 AAPB 사용을 이어갈 수 있습니다.
