# 번역 정책

기능 설명의 기준 원문은 영어입니다. 한국어는 사람이 읽는 문서이며 영문 동작이나 안내가 바뀌면 같은 변경에서 갱신합니다.

## 기능은 맞추고 표현은 독자에게 맞추기

명령, 파일명, 수치 한도, 지원 동작, 이전 규칙, 검증 주장은 일치해야 합니다. 사실이 다르면 영어 원문, 현재 코드, 의도한 명세를 비교하고 필요한 경우 양쪽을 고칩니다.

소개나 페이지 구조까지 똑같아야 한다는 뜻은 아닙니다. README의 로고, 배지, 언어 선택과 의도한 한국어 설명·기능 요약을 보존하세요. 한국어 사용자가 혼용된 기술 용어를 이해하려고 영어판을 다시 열어야 하지 않도록 씁니다.

| 해당하면 그대로 보존 | 이해하기 쉽게 조정 |
| --- | --- |
| 명령 이름, 옵션, JSON 필드, 경로, URL, 수치 | 주변 설명, 예시 문장, 제목, 탐색 링크 이름 |
| 동작 조건과 불확실성 | 설명 순서와 자연스러운 한국어 표현 |
| 의도한 문체와 강조 | 문서 독자에게 맞는 어휘 |

예를 들어 `metadata`는 관리 정보, `cursor`는 다음 결과를 가져올 때 쓰는 값이라고 먼저 설명합니다. 실제 결과 필드 이름은 코드 글꼴로 유지합니다.

## 파일과 설치 규칙

- 스킬, 템플릿, 문서, 예시, 어댑터의 기준 원문은 영어로 둡니다.
- 한국어는 `translations/ko`에 두고 가능하면 원본 경로를 유지합니다.
- 파일명은 `.ko.md`를 사용합니다. 스킬 번역은 `SKILL.ko.md` 대신 스킬 이름을 씁니다.
- 번역 폴더에 설치형 `SKILL.md`를 만들거나 사용자 스킬 위치로 동기화하지 않습니다.
- 언어 선택에는 `한국어` 같은 해당 언어의 이름을 쓸 수 있습니다.
- 한국어 문서가 있으면 링크도 한국어 경로로 연결합니다. 이미지와 라이선스는 더 깊은 폴더에 맞게 상대 경로를 조정합니다.

## 대응 파일뿐 아니라 의미 검토하기

번역과 공개 문서 검사를 실행합니다. 그다음 변경된 명령, 조건, 결과를 대조하고 한국어 문장을 읽어 이해 가능한지 확인합니다. 원문마다 번역 파일이 있다는 검사로 내용의 충분함, 문체, 독자가 따라갈 경로까지 검증되지는 않습니다.

에이전트 스킬을 짧게 쓴다는 기준을 초보자 안내나 참조 문서의 길이 제한으로 적용하지 않습니다. 항목을 옮기면 두 언어 모두 찾을 수 있는 링크를 남기세요. [유지보수 안내](maintenance.ko.md)를 참고합니다.
