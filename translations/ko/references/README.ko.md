# 선택 참조 라이브러리

0.5 세대의 분야별 계약·예시·예외 처리를 보존합니다. 스킬 목록으로 설치하거나 시작할 때 전부 읽지 않습니다. 필요한 분야의 파일만 선택합니다. 과거 절차 조언과 종료된 명령은 현재 요건이 아니며 최신 과제와 1.0 명령 가이드를 따릅니다. 이전 위치는 docs/skill-decisions.json에 있습니다.

디자인·한국어 문서는 현재의 짧은 진입점을 사용합니다. 코드 구조 정리는 quality/cleanup-ai-slop 아래 별도 선택 참조로 남깁니다. 과거 진입점은 고정 0.5.11 패키지에서 복구할 수 있습니다.

현재 루트 지침과 아키텍처 선택은 [프로젝트 템플릿](../templates/agents/README.ko.md)과 [아키텍처 안내](../docs/project-architecture.ko.md)를 사용합니다. 템플릿 이전표에서 제거한 기술별 루트 파일과 선택형 참고 자료의 대응을 확인할 수 있습니다.
