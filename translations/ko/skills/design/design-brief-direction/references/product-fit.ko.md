# 제품 적합성과 방향

장식보다 사용자 과제와 가장 중요한 제품 제약을 먼저 확인합니다.

| 화면 | 유용한 강조 | 보존할 요소 |
| --- | --- | --- |
| 운영 테이블 | 비교·필터·빠른 탐색 | 정보 밀도와 상태 표시 |
| 편집기 | 콘텐츠·도구·복구 | 작업 공간과 키보드 흐름 |
| 상품 화면 | 살펴볼 수 있는 상품과 선택 | 제품 정체성·가격·행동 |
| 캠페인·포트폴리오 | 이야기와 브랜드 표현 | 의도한 색상·형태·모션 |

참고 자료에서 계층·간격·밀도·글자·상호작용 중 무엇을 가져오는지 밝힙니다. 재사용 원칙과 원래 브랜드 자산을 구분합니다. 구현에 필요한 토큰·상태·반응형 동작만 정리하고 이미지에서 보이지 않는 데이터 동작을 추측하지 않습니다.

예: 캠페인의 의도적인 그라데이션은 유지하면서 낮은 대비를 고칩니다. 운영 화면에서는 주요 작업을 가리는 큰 소개 영역을 줄입니다. 어느 쪽도 그라데이션·히어로의 일괄 금지가 아닙니다.

기존 선호와 승인된 예시를 사용합니다. 새 선호는 사용자가 실제로 선택했을 때만 기록하며 생성 예시 하나로 취향을 추정하지 않습니다.
