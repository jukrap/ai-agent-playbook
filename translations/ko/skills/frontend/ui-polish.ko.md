# UI 검토와 다듬기

렌더링한 화면과 사용자 과제를 확인합니다. 기존 디자인 시스템의 소유권과 의도된 표현을 유지합니다. 검토 요청은 발견 사항을, 수정이 허용된 요청은 해당 범위의 개선을 바로 수행합니다.

구체적인 점검이나 전후 비교가 필요할 때 rendered-review 참조를 읽습니다. 작고 명확한 편집에는 참조를 읽을 필요가 없습니다. 정적 검사 결과는 후보이며 자동 결함 판정이 아닙니다. 스타일 관례가 충돌할 때만 상세 정책을 읽고 별도의 polish·스타일 선택·generic UI 스킬을 연쇄 실행하지 않습니다.
