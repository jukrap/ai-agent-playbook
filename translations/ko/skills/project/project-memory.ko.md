# 프로젝트 기록

CURRENT.md 같은 프로젝트의 기존 기록 진입점에서 현재 목표, 제약, 다음 행동과 링크를 찾습니다. 관련 기록만 읽고, 지원되는 저장소·주제·월·종류·경로 필터로 먼저 범위를 좁힌 뒤 필요하면 넓힙니다. 일상적인 편집마다 작업 일지를 새로 만들 필요는 없습니다.

의미 있는 단계 완료, 결정, 중요한 사실 확인, 차단과 인계를 기록합니다. 재사용할 현재 사실은 주제별 지식 문서에, 상세 근거는 날짜별 작업 일지에 두며 새 구조에서는 월별 폴더를 사용합니다. 기존 기록, 관리 주체, 근거 위치와 로컬 전용 규칙을 보존하고 의도한 계약, 구현, 설정과 관측한 동작을 구분합니다.

작업 공간의 공통 기록은 명시적으로 등록된 구성원에만 적용됩니다. 코드나 Git 작업 전에 선택한 저장소를 확인하세요. 기록 위치만으로 코드 대상이 정해지지는 않습니다. 기록에는 Git이 필요하지 않습니다.

현재 상태를 갱신하거나 작업을 재개할 때는 [현재 상태](project-memory/references/current-state.ko.md)를 읽습니다. 상세 근거, 인수인계나 선택적인 독립 DRAFT 작업에는 [근거와 인수인계](project-memory/references/evidence-and-handoff.ko.md)를 참고하세요. 기록은 보통 메인 작업에서 직접 작성하며, 위임한 초안은 메인이 검토한 뒤 반영합니다. 호스트 메모리는 선택 사항이므로 일반 파일만으로 진행할 수 있습니다.
