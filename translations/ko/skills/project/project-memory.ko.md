# 프로젝트 기록

CURRENT.md를 현재 목표·제약·다음 단계·근거 링크를 찾는 짧은 진입점으로 유지합니다. 해당 과제와 관련된 기록만 읽으며 일반적인 작은 편집마다 작업 로그를 새로 만들지 않습니다.

의미 있는 이정표에서 결정과 확인한 사실을 기록합니다. 근거 위치를 보존하고 구현·설정·실제 실행 결과를 구분합니다. 프로젝트의 소유권과 로컬 전용 정책을 따릅니다.

현재 상태 갱신·재개에는 current-state 참조를, 결정·인수인계에는 evidence-and-handoff 참조를 읽습니다. 호스트 메모리가 없어도 일반 파일로 진행할 수 있습니다.
