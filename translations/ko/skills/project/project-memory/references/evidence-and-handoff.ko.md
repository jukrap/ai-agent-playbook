# 근거와 인수인계

중요한 결정에는 선택한 동작·이유·영향받는 계약·근거 위치·남은 불확실성·다음 행동을 기록합니다. 대안은 실제 절충을 설명할 때만 남깁니다.

완료·잔여 작업, 보존할 제약, 근거를 다시 확인할 파일·명령을 전달하고 대화 전체를 중복하지 않습니다.

## 근거 구분

- 설정됨: 설정이나 도구 등록이 존재합니다.
- 로딩됨: 호스트에 실제 기능이 노출됩니다.
- 실행됨: 특정 환경에서 특정 과제를 수행했습니다.
- 검증됨: 완료 조건을 실제로 확인했습니다.

부재 주장은 검색 범위와 제외 파일을 밝힙니다. 생성 보고서와 과거 요약을 새 정책으로 삼지 않습니다. 확인하지 못하면 unknown으로 남깁니다. 지속적인 결정이 없는 작은 편집마다 기록을 요구하지 않습니다.
