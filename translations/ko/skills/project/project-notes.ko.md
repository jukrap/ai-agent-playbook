# 프로젝트 메모

세션 사이에 이어 쓸 간단한 프로젝트 메모를 유지할 때 사용합니다.

프로젝트의 기존 현재 상태 진입점을 사용하고 작업에 필요한 근거만 읽습니다. 현재 목표, 제약, 확인한 상태, 다음 행동과 유용한 링크를 간결하게 유지합니다. 기존 형식을 따르며 별도 기록 체계를 만들거나 모든 응답을 기록하지 않습니다.

의미 있는 단계가 끝나면 결정과 실제 수행한 검사를 기존 기록에 반영합니다. 의도한 동작, 확인한 결과, 모르는 부분을 구분합니다. 이전 근거, 사용자 수정과 로컬 전용 규칙을 보존하고 비밀 정보는 기록하지 않습니다. 공통 작업 공간에서는 코드나 Git 작업 전에 명시적으로 등록된 저장소를 선택합니다. 공통 메모가 여러 저장소의 변경을 허용하지는 않습니다.

응답과 결과물은 수행한 작업, 결과와 한계에 집중합니다. 요청하지 않은 작업 방식의 브랜드명이나 스킬명 설명은 생략합니다. 사용 방법에 관한 직접 질문에는 사실대로 답하고 필수 고지와 출처 표기를 따릅니다. 이 지침은 권한, 감사 기록이나 실행 앱의 지침을 바꾸지 않습니다.

실행 앱의 기존 도구를 사용합니다. 추가 지침은 작업에 필요할 때만 읽습니다. 이 스킬에는 참고 자료 묶음이나 필수 동반 스킬이 없습니다.
