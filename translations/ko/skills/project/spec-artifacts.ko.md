# 규격 산출물

요청한 산출물만 작성합니다. 프로젝트의 형식과 기존 근거를 재사용하며 계획 절차·고정 읽기 순서·모든 산출물 작성을 요구하지 않습니다.

의도한 요구사항과 현재 구현을 구분합니다. 관련 저장소나 등록된 작업 공간 구성원, 기존 기록 위치를 확인하세요. 공통 기록이 있다고 해서 여러 구성원의 코드나 Git 작업이 허용되지는 않습니다. 로컬 전용 규칙과 사용자의 승인 조건을 보존합니다.

선택한 문서의 필드는 [산출물 형식](spec-artifacts/references/formats.ko.md)을 확인합니다. 관련된 공개 API·데이터·버전·이전 제약을 보존하고 실제 수행한 검증만 기록합니다. 분야별 예시는 저장소 참조 라이브러리의 선택 자료이며 필수 선행 자료가 아닙니다.

길고 독립적인 산출물의 DRAFT를 선택적으로 위임할 때는 범위를 정한 근거와 짧은 관련 이력을 전달합니다. 메인은 보존해야 할 사실과 미확인 사항을 검토한 뒤 채택하며, 일반적인 산출물은 메인 작업에서 작성합니다.
