# 선택한 산출물의 형식

저장소 템플릿을 우선하고 결정 규모에 맞게 필드를 줄입니다.

| 산출물 | 필요한 내용 |
| --- | --- |
| 명세 | 문제·의도한 동작·제약·완료 조건 |
| ADR | 결정·이유·관련 대안·결과 |
| 계약 | 생산자/소비자·기존/새 형식·호환성·실패 동작 |
| 이전 | 시작 상태·미리보기·적용·충돌·검증·복구 |
| 인수인계 | 완료·잔여·제약·근거·다음 행동 |
| 릴리스 노트 | 사용자에게 달라진 점·호환성·필요한 조치·한계 |
| 검증 기록 | 명령/관찰·환경·결과·제외한 범위 |

선택 필드의 부재를 차단 조건으로 만들지 않습니다. 결과를 바꾸는 결정만 질문으로 남깁니다. 계약은 실제 출처를 명시하며 이름만으로 schema를 만들지 않습니다. 검증표는 구현을 줄마다 되풀이하지 않고 의미 있는 위험을 확인합니다.

커밋·PR 형식은 설정된 프로젝트·호스트 정책을 따르며 중복 승인 절차를 추가하지 않습니다. 이미 승인된 로컬 이정표는 진행하고 원격 게시는 별도 범위로 둡니다.
