# 개인 Codex 지침 템플릿

[AGENTS.md](AGENTS.ko.md)는 여러 프로젝트에 공통으로 적용할 대화, 허용된 작업, 도구, 작업 연속성, 검증과 Git 전달 기준을 제공합니다. 프로젝트 루트 지침이나 아키텍처와는 별개입니다.

일반적인 개인 파일 위치는 `~/.codex/AGENTS.md`입니다. Codex 홈을 바꿨다면 위치도 달라지므로 적용 전에 설치된 앱의 설정을 확인하세요. 패키지 안의 파일은 템플릿이며 현재 앱이 사용하는 실제 파일과 같다고 가정하지 않습니다.

## 검토하고 반영하기

현재 개인 지침과 비교해 원하는 선호를 반영합니다. 사용자의 언어, 명시적 승인 조건과 기존 사용자 규칙을 보존하세요. 패키지 설치, 스킬 설치와 프로젝트 부트스트랩은 개인 파일을 설치하거나 덮어쓰지 않습니다.

유용한 기본 지침을 알아보기 쉽도록 주제별로 나눴습니다. 스킬 진입점을 짧게 쓰는 기준이 이 파일의 길이를 정하지는 않습니다. 반복되는 필요를 해결하면 개인 규칙을 추가하고, 앱 동작과 중복되거나 현재 의도와 충돌하거나 더는 필요하지 않으면 덜어냅니다.

## 무엇을 어디에 두나요?

| 개인 기본 지침 | 프로젝트가 관리할 내용 |
| --- | --- |
| 설명의 언어, 문체와 근거 | 제품 용어와 인수 조건 |
| 허용 범위 안에서 진행하고 편집을 보존하는 원칙 | 배포 권한과 저장소별 Git 절차 |
| 유용한 도구를 고르고 진행 상태를 남기는 기준 | 프레임워크, 패키지 관리자, 명령과 기록 위치 |
| 실제 검증과 전달 상태를 보고하는 기준 | 아키텍처, 공개 import, 데이터 관리 주체와 임시 예외 |

프로젝트 아키텍처는 해당 프로젝트에 두어 다른 프로젝트에 강제로 적용되지 않게 합니다. [프로젝트 지침](../agents/README.ko.md)과 [아키텍처 결정](../../docs/project-architecture.ko.md)을 참고하세요.

## 이전 템플릿과 달라진 점

대화, 비공개 정보, 범위, 불확실성, 검증과 전달 기준을 명시적으로 유지합니다. 예전의 고정 읽기 순서와 자동 생성 정책 파일 참조는 요구하지 않습니다. 현재 코드는 기존 동작의 근거이며, 구현이 다르다는 이유로 채택한 프로젝트 요구사항보다 우선하지 않습니다.

이 템플릿은 모델, 문맥·출력 수치, 플러그인 활성화나 실험 기능을 설정하지 않습니다. 스킬과 선택형 MCP는 [Codex 설정](../../adapters/codex/README.ko.md)에서 따로 설명합니다.
